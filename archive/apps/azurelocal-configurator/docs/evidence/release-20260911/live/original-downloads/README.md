# Original downloads (0.1.0 release record)

These are packages downloaded from the live 0.1.0 release on 2026-09-11.

On 2026-09-13 three packages were removed at the owner's request:

- `azurelocal-ansible-design.zip`
- `azurelocal-terraform-design.zip`
- `azurelocal-toolkit-design.zip`

They contained generated Terraform, Ansible and converter code. The configurators now export data only, never automation code. The JSON summaries in `../` and `CHECKPOINT.md` still list these files as history of what 0.1.0 produced. The copies remain in git history before this removal.

`azurelocal-design.zip` and `azurelocal-imported-design.zip` contain no automation code and are kept.
